# SideNote

SideNote is an experimental browser extension for asking focused follow-up questions about a passage in an AI conversation while keeping the original answer in view.

The complete source, setup guide, architecture notes, security model, integration proposal, and evaluation fixtures are in [`sidenote-extension/`](sidenote-extension/).

SideNote is an independent prototype and is not affiliated with or endorsed by the AI providers whose websites it can work with. The browser adapters are best-effort and may stop working when those sites change. This project is released under the [MIT License](LICENSE).

## Quick start

- **Try the unpacked extension:** follow the [installation guide](sidenote-extension/README.md#install-in-chrome-or-chromium).
- **Run the local interactive preview:** follow [Preview and local backend](sidenote-extension/README.md#preview-and-local-backend).
- **Review the security scope:** read [`SECURITY.md`](sidenote-extension/SECURITY.md).

The project is an engineering MVP and has not received an independent security review or formal compatibility qualification. See the project README for supported hosts, setup requirements, limitations, and developer checks.
