Here’s a quick example of how NumPy can randomly select a sample of student IDs without choosing the same student twice:

sample = np.random.choice(students, size=5, replace=False) print(sample)

This selects five distinct student IDs.

Where is it useful?

  • Initializing model parameters.
  • Creating synthetic datasets.
  • Sampling data for experiments.
  • Running simulations.
  • Randomly splitting or selecting observations.

Important: NumPy also provides the newer random-number interface through np.random.default_rng().

For new code, this is generally the preferred approach.
